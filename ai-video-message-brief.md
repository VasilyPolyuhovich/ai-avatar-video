# AI кругові відео-повідомлення — project brief

> Переформатовано зі старого плану під правильний старт: розділено «що будуємо»
> (домен) від «на чому будуємо» (інфраструктура RunPod). Інфра-частина спирається
> на скіл `runpod-vllm-serving` (уроки з реального деплою на RunPod).
> **Статус даних:** технічний стек звірено на липень 2026 — див. позначки ⚠️ ПЕРЕВІРИТИ.

## 1. Мета

Генерувати talking-head відео з фото людини + аудіо (lip sync + стримані жести),
self-hosted на RunPod, у форматі, придатному для Telegram video note.

**Ключове уточнення (лишається вірним):** «кругле відео» — не стиль генерації.
Telegram круглить квадратне відео на клієнті. Технічно це **avatar/talking-head
generation з lip sync**. Ручне circular-маскування не потрібне.

## 2. Вихідні дані та обмеження

| Параметр | Значення |
|---|---|
| Джерело аватара | одне чітке, добре освітлене **фото** конкретної людини (без відео) |
| Аудіо | ⚠️ ВІДКРИТЕ: власний голос vs TTS-клон; мова — **українська** (впливає на вибір TTS) |
| GPU | A100 80GB або H100 (Secure Cloud) — пріоритет **максимальна якість** |
| Вивід | квадратний MP4/H.264, ≤60 c, diameter ~384–640px; thumbnail JPEG ≤200KB/≤320px |
| Робочий режим | **batch/інтерактивний рендер**, НЕ always-on сервіс |

## 3. Рішення: стек генерації

**Обрано:** Wan2.1 14B I2V (720p) + **InfiniteTalk** у ComfyUI (full fp16, VRAM дозволяє).
InfiniteTalk редагує весь кадр (голова/поза/жести), а не тільки рот — найкраща якість
руху серед відкритих, до 10 хв аудіо.

⚠️ **ПЕРЕВІРИТИ перед стартом (дані рухаються швидко):**
- **Wan2.2 уже вийшов** — чи є InfiniteTalk на Wan2.2-бекбоні? Новіший бейс = краща база. Якщо так — брати його.
- **A/B-альтернатива:** `HunyuanVideo-Avatar` (emotion-control, мульти-стиль, сильна ідентичність). Для довгих кліпів — `Hallo3` (боротьба з identity-drift). Варто швидко порівняти на своєму фото перед тим, як фіксувати стек.

**Ваги (десятки ГБ — критично для інфри, п.5):**
`wan2.1_i2v_720p_14B_fp16` (~28GB), `Wan2_1-InfiniteTalk-Single_fp16`, Wan2.1 VAE,
UMT5-XXL fp16 (~11GB, не scaled), `clip_vision_h`, Wav2Vec2 (audio encoder). Разом ~50–70GB.

## 4. Pipeline

1. Вхід: фото + аудіодоріжка (голос/TTS).
2. ComfyUI: Load Image → CLIP Vision → WanVideo I2V + InfiniteTalk node (audio-conditioned + текстовий промпт жестів) → кадри.
3. **Frame interpolation** (подвоєння FPS) — обов'язково, прибирає мерехтіння.
4. Експорт: квадратний MP4/H.264, ≤1 хв.

**Жести:** керуються текстовим промптом у тому ж вузлі, напр.
*"A person speaks warmly, occasionally gesturing with one hand while explaining"*.
Руки/пальці — найслабше місце; прості стримані жести надійніші. Генерувати кілька
seed-ів на 480p, відбирати найкращий, фінал рендерити у 720p.

## 5. RunPod інфраструктура — застосований досвід (skill: `runpod-vllm-serving`)

> Це найважливіша частина для «правильного старту». Дифузійне відео ще важче за LLM
> по VRAM/compute, а ваги — десятки ГБ, тож **персистентність вирішує все**.

### 5.1 Персистентність — головна пастка
| Шар | Виживає Stop→Start | Виживає Delete | Куди класти |
|---|---|---|---|
| container root `/` | ❌ (recreate) | ❌ | нічого важливого |
| pod-локальний том | ✅ | ❌ знищується з подом | — |
| **network volume** | ✅ | ✅ переприкріпний | **ComfyUI + усі ваги + custom nodes** |

- **Бери network volume, не pod-локальний.** Ваги 50–70GB не хочеш качати повторно
  при кожному recreate. Мережевий том переживає навіть видалення пода.
- **ComfyUI + кастомні ноди — на том, не в root.** `pip install` ComfyUI/нод у
  системний Python стирається при Stop→Start (той самий урок, що з vLLM). Став ComfyUI
  у `/workspace`, а `models/` — на томі (симлінк або `--base-directory`), custom_nodes теж.
- **Recovery після рестарту:** якщо все на томі — просто перезапустити ComfyUI (одна
  команда), без перезавантаження ваг.

### 5.2 Диск і CUDA
- **Container disk ≥60GB** (torch+CUDA+ноди роздуваються при install; 20GB переповниться).
- **Network volume ≥100GB** (ваги ~50–70GB + виходи-відео + кеш).
- **CUDA/драйвер:** SageAttention/Triton чутливі до версії CUDA — той самий клас проблем,
  що `libcudart.so.13` у vLLM. Бери **новий-драйвер хост** (A100 80GB/H100, `--min-cuda-version 12.9`);
  L40S/старі хости часто мають задряй драйвер. Якщо accel-ліби не бачать libcudart —
  дивись `LD_LIBRARY_PATH` (див. skill → vllm-and-models.md, розділ cu13).

### 5.3 Образ / темплейт (швидкий, відтворюваний старт)
- Стартуй з **готового ComfyUI-темплейта з SageAttention/Triton**; зафіксуй (pin) версію.
- Кастомні ноди: `ComfyUI-WanVideoWrapper` (Kijai) + InfiniteTalk — **зафіксуй git-commit**
  (ноди ламаються між версіями).
- **Для повністю відтворюваного recreate — власний Docker-образ** (base ComfyUI + accel +
  ноди, БЕЗ ваг — ваги на томі). Тоді новий под просто тягне образ. При збірці в CI —
  пам'ятай про «free disk space» крок (образ величезний). Деталі — skill →
  deploy-and-durability.md.

### 5.4 Доступ
- ComfyUI UI — порт **8188**; відкрий HTTP-порт пода або ходи через **SSH-тунель**
  (`ssh -N -L 8188:localhost:8188 …`) — приватніше (проксі RunPod термінує TLS).
- SSH-рецепт (ssh-rsa + `-tt` + PTY, суфікс із Connect-панелі) — skill → runpod-api-and-ssh.md.

### 5.5 Вартість — важливо для цього навантаження
- Рендер відео **довгий і GPU-важкий**, A100/H100 дорогі. Це **batch**, не always-on:
  **Stop, коли не рендериш** (не тримай под простоювати).
- Постав **бюджетний вартовий** (баланс/runway через RunPod API) і, за бажанням,
  **daily self-stop** — обидва вже описані в skill → runpod-api-and-ssh.md. Ключ на під
  клади безпечно (секрети через SSH echo-ляться — хай пише людина, не автоматизація).
- ⚠️ Пам'ятай: **зупинка Secure-пода може завадити рестарту** (GPU заберуть). Для дорогих
  H100 плануй сесії рендеру.

## 6. Формат виводу (Telegram video note)
Квадрат (w=h), MP4/H.264, ≤60c, diameter 384–640px, thumbnail JPEG ≤200KB/≤320px.
Круглення — на клієнті Telegram, маскування не потрібне.

## 7. Відкриті питання (вирішити до кодингу)
1. **Аудіо:** власний голос vs TTS-клон під **українську** (якість укр-TTS — окреме дослідження).
2. **Стек:** підтвердити Wan2.1 vs Wan2.2-InfiniteTalk; швидке A/B з HunyuanVideo-Avatar на своєму фото.
3. **Образ/темплейт:** конкретний ComfyUI-темплейт + pin версій нод, або власний Docker-образ.
4. **Том:** створити network volume (≥100GB) заздалегідь, у тому ж DC, що й под.

## 8. Перші кроки (щоб стартувати правильно)
1. Створити **network volume ≥100GB** у Secure DC (напр. EU-RO-1).
2. Підняти под A100 80GB/H100 Secure з цим томом на `/workspace`, container disk ≥60GB,
   відкрити 8188, `--min-cuda-version 12.9`.
3. Поставити ComfyUI + WanVideoWrapper + InfiniteTalk **у `/workspace`**, ваги — у `/workspace/models`.
4. Швидкий smoke-тест: одне фото + 5–10c аудіо → 480p, перевірити sync/ідентичність.
5. Паралельно — A/B стеку (п.7.2) і рішення по аудіо (п.7.1).
6. Зафіксувати робочий стан: recovery-команда + (за потреби) Docker-образ + self-stop/бюджет.
